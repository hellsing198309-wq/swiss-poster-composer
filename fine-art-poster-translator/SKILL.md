# Fine Art Poster Translator

## 目标

把一张真实上传照片转译成一张独立的 3:4 高级艺术海报。上半部是经过轻微高级调色的真实摄影，下半部是在暖白纸张留白中的艺术媒介转译。两部分必须一眼看出是同一个主体：上方记录对象，下方解释对象。

这是一套偏艺术展、艺术书、博物馆商店艺术印刷品与独立出版物的视觉规则。它追求安静、准确、有材质的表达，不追求模板化装饰，也不把照片简单套成插画滤镜。

## 输入与输出

- 输入：一张上传照片，或一组需要逐张处理的照片。
- 输出：每张照片一张独立的完整海报；一张照片只能对应一张海报。
- 多张输入必须逐张生成，禁止拼接、合成、分屏或把多张照片放进同一张海报。
- 最终画幅为 3:4 竖版，上下区域约各占 50%。
- 若没有可用照片，不要凭空创造一个“相似题材”；先要求用户提供照片。

## 不可偏离的硬约束

1. **单图独立输出**：当前照片是当前海报的唯一视觉来源。不同照片之间可以共享版式气质，但不能共享主体、动作、颜色逻辑或艺术图案。
2. **上下约 1:1**：上半部为真实摄影，下半部为艺术转译。分界清晰，不能把下半部缩成小图，也不能让摄影部分吞没整个画面。
3. **主体不变形**：必须保持原主体的外形、比例、结构、姿态、材质、方向和关键识别特征。可以为了 3:4 画幅自然延展天空、墙面、地面、水面或环境，但不得拉伸、扭曲或改变主体比例。
4. **同一主体的转译**：下半部必须来自上方照片中最具识别性的轮廓、比例、结构、姿态、色彩、材质或关键局部；不得用随机图案、无关景物或另一个主体替代。
5. **中央留白构图**：下半部主体放在中央，约占下半区域的 45%–70%；主体周围必须保留充足米白、暖白、象牙白、浅灰白或天然纸张留白，不得铺满下半部。
6. **文字极少**：文字面积不得超过下半部的 5%。默认只使用 `OBJECT STUDY`、`FORM 01`、`SERIES / 2026` 这类短信息；无法稳定生成字母时宁可省略，也不要输出乱码。
7. **真实摄影部分不绘画化**：上半部不能变成水彩、油画、3D 渲染、卡通或塑料质感。艺术媒介只作用于下半部。

## 上半部：真实摄影

上半部完整保留上传照片中的真实主体与环境氛围，并遵循高级艺术摄影、Editorial Photography、画廊档案摄影的标准。

- 保留主体的外形、空间位置、比例、姿态、方向、材质与识别特征。
- 轻微控制白平衡、色噪声、饱和度、对比度和高光，使画面克制、准确、耐看。
- 保留自然光影、真实材质和原始空间关系；不能为了“高级”强行改变时间、天气或环境叙事。
- 允许自然延展天空、墙面、地面、水面、建筑背景或自然环境来适配 3:4，但延展区域应服从原照片的光线、景深和透视。
- 不随意增加不存在的重要物体，不替换人物、动物、建筑、乐器、车辆或其他核心对象。
- 摄影部分不添加绘画笔触、纸张纹理、装饰性笔刷或无关 UI 元素。

## 下半部：艺术媒介转译

下半部不是照片复制，也不是普通写实插画，而是对同一主体的艺术化概括。默认使用克制的透明水彩 / 墨彩纸上绘画语言，因为参考样本呈现的是自然纸张、稀释颜料、边缘渗化和少量干笔触；如果用户指定版画、拼贴、炭笔、丝网印刷或其他媒介，必须以用户指定媒介为准。

转译时优先提取：

- 主体外轮廓与比例
- 姿态、运动方向或人与环境的关系
- 建筑、器物、动物身体或服装的关键结构
- 水平线、倒影、枝条、乐器、车轮、屋顶、拱形或其他可识别局部
- 2–5 个来自照片的核心颜色，并降低到适合纸面印刷的强度
- 能够说明材质的少量笔触、干湿变化或纸面边缘

构图必须遵循“大面积留白 + 中央独立艺术图案”：

- 主体集中在下半部中央，必要时保留少量与主体有直接关系的环境线索。
- 留白应成为构图的一部分，而不是被剩余画面填满的空地。
- 艺术图案可以有自然的水彩边缘、墨色晕染或轻微颜料飞溅，但不能变成脏乱的装饰背景。
- 不要把下半部做成全幅纹理、复杂场景或满版插画。
- 人物的身份可以适度概括，但姿态、数量、相互关系、服装大色块和所在位置必须与照片对应。
- 动物要保留身体比例、姿态、羽毛 / 毛发方向、眼睛或喙等关键识别点，避免卡通化和 Q 版。
- 建筑与器物要保留轮廓、透视、材料重量和关键开口；不要只画一个泛化的“建筑符号”。

## 主体到媒介的选择

当用户没有指定媒介时，使用与主体相称的克制水彩 / 墨彩；不要在不同照片之间机械复制同一张抽象模板。

| 主体 | 优先保留的转译线索 | 推荐处理 |
| --- | --- | --- |
| 风景、海面、倒影 | 地平线、天空层次、倒影方向、人物或器物的尺度 | 大留白中的水平水彩洗染，保留倒影但删掉无关细节 |
| 鸟、动物 | 身体轮廓、姿态、羽毛 / 毛发、眼睛、枝条或栖息物 | 透明色层与少量干笔触，避免拟人和卡通线稿 |
| 人物、情侣、舞者 | 人数、姿态、服装轮廓、手势、相互距离、地面关系 | 以姿态和色块为主，脸部不做塑料化精修 |
| 乐器、文化场景 | 人与乐器的关系、材质、弦 / 杆 / 鼓面、圆形结构与现场线索 | 水彩、墨线和少量干刷并置，保留文化对象的识别性 |
| 建筑、塔楼、器物 | 外轮廓、透视轴、屋顶、拱门、重复结构和材质块面 | 纸上建筑速写式水彩，边缘留出呼吸感 |

## 色彩与文字

- 从当前照片提取 2–5 个核心色，优先保留主体的真实色彩关系。
- 以米白、暖白、象牙白、浅灰白或天然纸色作为下半部基础；纸张应轻微有材质，但不能喧宾夺主。
- 允许少量深灰、棕、赭、蓝、绿或橙作为主体锚点；避免廉价荧光色、赛博霓虹与大面积发光渐变。
- 文字使用现代、安静的无衬线或细衬线展览标签风格，左对齐或居中时必须有明确理由；字号小，层级少。
- 可使用：`OBJECT STUDY`、`FORM 01`、`SERIES / 2026`。用户指定标题时，优先使用用户标题，但仍需控制面积与数量。

## 执行流程

1. **逐张分析**：只分析当前照片，记录主体、环境、比例、姿态、关键材质、方向、2–5 个核心色和下半部最值得保留的识别线索。
2. **锁定版式**：建立 3:4 竖版画布，上下约各 50%，确定安全边距和下半部中央留白区。
3. **处理摄影**：将当前照片放入上半部，只做轻微高级调色和必要的自然环境延展；检查主体没有被拉伸、替换或绘画化。
4. **选择媒介**：若用户指定媒介，严格执行；否则使用克制的水彩 / 墨彩纸面语言，并让媒介服务于主体特征。
5. **绘制转译**：在下半部中央重建同一主体，保留关键轮廓、比例、姿态和材质线索；删除非必要细节，扩大周围留白。
6. **加入信息**：只添加少量英文标题、编号和年份；文字占下半部不超过 5%，不盖住主体。
7. **最终校验**：确认一张照片对应一张海报；3:4；上下约 1:1；上方是真实摄影；下方是同一主体的艺术媒介转译；主体居中且占比 45%–70%；纸张留白充足；没有拼图、变形、随机背景或 AI 塑料感。

## 禁止项

- 禁止多图拼接、分屏、照片合成或把不同照片放入同一张输出。
- 禁止把上半部照片替换为新的 AI 场景、相似主体或泛化素材。
- 禁止把下半部做成满版插画、卡通、Q 版、游戏概念图、复杂场景或随机几何海报。
- 禁止随意增加重要人物、动物、建筑、车辆、乐器或装饰物。
- 禁止廉价滤镜、过度锐化、塑料皮肤、厚重渐变、赛博 UI、复杂文字和乱码。
- 禁止把本 Skill 自动变成 Swiss Grid 几何海报；如果用户要求严格瑞士网格与几何色块，请改用 `$swiss-poster-composer`。
